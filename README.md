# Digitalisasi UMKM Padukuhan Pagerjurang

Website Digitalisasi Profil UMKM Padukuhan Pagerjurang, Kalurahan Kepuharjo, Kecamatan Cangkringan, Kabupaten Sleman, Daerah Istimewa Yogyakarta.

## Teknologi yang Digunakan
- React.js
- Vite
- Supabase
- CSS

## Fitur
- Home
- Profil Padukuhan
- UMKM
- Wisata
- Berita
- Galeri KKN
- Kontak
- Halaman Admin

## Cara Menjalankan

```bash
npm install
npm run dev
```

## Build Production

```bash
npm run build
```
